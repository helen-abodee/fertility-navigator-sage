Fertility Preservation Navigator

Iteration 3

November 1, 2026. The options experience, rebuilt: less reading, more tapping.

Options, redesigned

  • Badges gone. Each option is now a simple row: icon, name, one line. Tap to go deeper. (The "not a replacement for freezing" caution for ovarian suppression survives inside its detail page, since that one is safety-relevant.)
  • Steps are a swipe. Inside an option, the steps are swipeable cards: one icon, one step, a sentence or two. Swipe or tap the dots and arrows. Egg freezing is 4 swipes instead of a wall of text.
  • Icons are built in. A consistent hand-drawn-feel line set (egg, embryo, syringe, snowflake, flask, and so on), all inline SVG, both themes. They're referenced by key, so if you ever get designer illustrations we swap files, not code. No need to go find icons unless you want a more illustrated look.
  • "What would this look like for me?" opens a personal timeline: first visit and tests, about 10 to 12 days of shots with check-ins, retrieval (asleep for it), freezing, with the sourced durations and the honest note that it usually doesn't wait for a menstrual cycle.

The cost estimate

Each option now has "What could this cost you?": it adds only the published prices (never an invented number), with a slider for years of storage, and then frames it by their insurance answer: CA commercial pre-treatment gets the SB 600 "your plan should cover this, ask what you'd owe" framing; survivors get the SB 729 framing; Medi-Cal gets the honest "not covered, plan around these prices, aid exists" framing. Lines with no published price are listed as "not included" instead of being guessed. The math is unit-tested, and everything carries its citation.

Example on the agreed path (egg freezing, 5 years of storage): $12,400 cycle + ~$5,000 medicines + 5 x $200 to $500 storage = $18,400 to $19,900 if paying published prices, with the SB 600 note that insurance may change that to plan cost-sharing.

Risk module, made swappable

Per your ask: the clinical mapping now lives in one file, lib/risk/rules.ts, as an ordered list of rules, each with its copy and citations. When Hannah's guidelines arrive, we edit or replace that one file, run the tests, and the app follows. Nothing else touches it.
